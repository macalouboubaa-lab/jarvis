# Direction UI/UX

## Direction visuelle existante

- Thème sombre inspiré d'Iron Man.
- Cyan néon comme couleur d'accent.
- Fond principal `#0A0E1A`.
- Texte principal `#E6F1FF`.
- Interface destinée à un assistant personnel avec chat, mémoire, emplois, paramètres et voix.

## Composants existants

- `Sidebar` pour la navigation principale.
- `ChatBubble` et `ChatInput` pour le chat.
- `JobCard` pour les opportunités professionnelles.
- `MemoryCard` pour les souvenirs.
- `VoiceWave` pour le retour visuel vocal.

## Principes d'expérience

- Rendre le statut de l'assistant et les états de chargement compréhensibles.
- Préserver une navigation directe entre chat, emplois, mémoire et paramètres.
- Rendre les interactions vocales utilisables au clavier lorsque c'est possible.
- Respecter les contrastes et les états de focus accessibles.
